## Why

В текущей реализации игрок может присоединиться к комнате только зная её ID — нет возможности увидеть список доступных комнат, в которых не хватает второго игрока. Это создаёт неудобство: чтобы найти игру, нужно либо договариваться с другим игроком о ID комнаты, либо создавать свою и ждать. Страница со списком комнат решит эту проблему, позволяя игрокам быстро находить доступные игры и присоединяться к ним.

## What Changes

- Новая страница `/rooms` со списком комнат, в которых не хватает игрока (есть свободное место)
- Напротив каждой комнаты — кнопка "Присоединиться", которая добавляет пользователя в игру на свободное место
- Кнопка "Создать игру" над списком, ведущая на страницу создания комнаты (`/room/create`)
- Новый эндпоинт `GET /rooms` для получения списка комнат со свободными местами
- Новый эндпоинт `POST /rooms/{roomId}/join` для присоединения к комнате
- Метод в `RoomRepository` для получения всех комнат, где есть свободное место

## Impact

- **Backend**: 
  - `RoomRepository` — новый метод `findRoomsWithAvailableSlot()` для поиска комнат со свободными местами
  - `RoomRepositoryImpl` — реализация нового метода
  - `RoomController` — новый эндпоинт `GET /rooms` (страница списка) и `POST /rooms/{roomId}/join` (присоединение)
  - `RoomService` — новый метод для получения списка доступных комнат
  - `RoomServiceImpl` — реализация нового метода
- **Frontend**:
  - Новый шаблон `/templates/room/index.html` — страница со списком комнат
  - Обновление навигации: ссылка на страницу списка комнат
